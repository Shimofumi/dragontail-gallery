# はじめに・三行的要約
- 中国語環境Windowsでは伺かの里々製ゴーストが正常に動作しないことがあります！
- 最新版の里々を入れることによって里々製ゴーストは正常動作するようになります。
- 原因は文字コードによるものです。
- 以下はしばらく中国語で解説したものをまず書き、後で日本語でどのようなものか説明します。
<br/>
- 在漢語環境下的Windows系統中，採用里々製作的偽春菜人格可能存在無法正常運行的情況！
- 在安裝最新版本的里々之後您的偽春菜人格即可正常運行。
- 原因在於字符編碼的問題。

### 漢語環境的解説
想必部分讀者在看到這篇文章時存在著漢語環境下運行日本語偽春菜ゴースト時啟動報錯或文章亂碼等諸多問題罷。
我與しもふみさん一起寫下這篇文章的初衷便是幫助大家解決這些問題((つ≧▽≦)つ那麼，請按照以下步驟進行操作哦！！！

注意事項  
人格=ゴースト  
氣球=バルーン  
因為日本語偽春菜人格的操作界面裡不會有漢語，所以正文使用日本語稱呼以幫助各位讀者更快完成操作！  

### 步驟一
首先，打開您的電腦的「文件資源管理器」，選中路徑欄中的「此電腦」，將其修改為任意您想要的名字（比如採用英語的PC），只要確保填入半角符號就可以啦！<br/>
<img src="/misc/ukagaka-advent-251214/SS0001.jpg" alt="Path" width="600" /><br/>
然後檢查您安裝SSP的文件夾，再次查看路徑欄，確保其中的路徑名稱全部為半角字符。完成上述操作後，檢查自己的SSP是否為最新版，若不是，請訪問<br/>
 https://ssp.shillest.net/ <br/>
 並更新您的SSP。接下來啟動SSP，看一看自己的偽春菜是否能夠在漢語環境下正常運作吧！

### 步驟二
這個步驟可能沒有太大的用處，但也有可能能幫到您就是啦（特別是對於那些剛入坑的同好們）…那麼首先，打開您的電腦的文件資源管理器，進入OS(C)也就是C盤，單獨創建一個新的文件夾，將從瀏覽器上下好的SSP安裝文件的下載地址修改為剛剛創建的那個文件夾。下載完成後啟動SSP，把想要安裝的ゴースト的nar文件或壓縮檔用鼠標選中，拖動到Emily/Phase4.5（也就是初始ゴースト）的身上，確認安裝之前點擊對應ゴースト的安裝提示的右下角的語言欄<br/>
<img src="/misc/ukagaka-advent-251214/SS0002.jpg" alt="Path" width="600" /><br/>
如圖所示，選擇Japanese(Shift-JIS)後即可確認安裝。如果只想使用日本語ゴースト的話那麼請右鍵自己的ゴースト<br/>
<img src="/misc/ukagaka-advent-251214/SS0003.jpg" alt="Path" width="600" /><br/>
如圖選擇「設定(O)」，然後選擇「本體設定（P）」（注意該選項不同ゴースト的選項名稱可能存在差異，多試幾次就好啦，一般來說是第一個）<br/>
<img src="/misc/ukagaka-advent-251214/SS0004.jpg" alt="Path" width="600" /><br/>
接下來如圖將語言選項全部改為Japanese(Shift-JIS)即可。如果此時您的偽春菜能夠在漢語環境下正常運行，那麼恭喜您不用接著看後面的部分啦(⁠･⁠◡⁠･⁠)⁠/<br/>

### 步驟三
這個步驟是用來解決日本語ゴースト的バルーン上文字的顯示問題的。如果您的ゴースト在運行時出現了バルーン上的文字排版錯誤或出現一些看起來像是ゴースト的系統參數的內容，請不要擔心。事實上，這可能是由參數的字符編碼不同導致的無法正常識別參數的問題。請按照以下方案操作即可：首先，確認您的ゴースト的語法（這裡以里々為例），確認完成後在語法對應的官網上下載其最新版本。下載完成後將壓縮檔解壓<br/>
https://github.com/ukatech/satoriya-shiori/releases<br/>
↑里々(satori)<br/>

請注意，以上的操作流程均為里々製日本語ゴースト專用，採用其它語法製作的偽春菜請前往其語法官網下載最新的語法壓縮檔！！！<br/>

### 關於一個小誤區
有些時候當我們嘗試使用日本語ゴースト但會話機能時，輸入一些簡單的日本語問候語可能會出現沒有反應的情況，這種情況下很可能是因為對應的ゴースト並沒有內置相關對話的回覆，所以會出現沒有響應的情況。<br/>


### 日本語話者向け解説
中国語環境Windowsで、Pathに日本語以外の2byte文字が入ると里々が正常に動作しないようです。<br/>
ponapalt氏が里々を更新してくれたので、更新しましょう。

ちなみに、中国語圏だと「伺か」は「偽春菜」と呼ばれ<br/>
「ゴースト」は「人格」<br/>
「バルーン」は「氣球」となっているようです。<br/>

そして、中国語圏では伺かはほとんど知られていないが、ファンはごくわずかながら存在しているようです。<br/>
古くからある、まゆらや蒼空の風詩、Taromatiなどが知られており、日本から覗けばタイムスリップしたかのような感想を覚えるかもしれません。<br/>
